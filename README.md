# Exe Monitoring Bot

Exécutable (bot compilé) qui surveille l'exécution de processus et envoie des notifications sur Microsoft Teams, avec journalisation locale des événements.

## Stack

- Exécutable Windows (.exe) packagé
- Notifications Microsoft Teams (webhook)

## Contenu

- `monitoringBotOnTeams.exe` — exécutable du bot
- `Json/` — fichiers de configuration/données
- `log.txt` — journal d'exécution
